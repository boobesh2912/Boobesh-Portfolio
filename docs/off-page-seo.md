# Off-page SEO checklist for boobesh.com and garitech.co.in

Code cannot do these for you. Each one is an action only you can take. Do them in this order. All of them are honest, visible and allowed by Google. Nothing here is hidden.

## 1. Google Business Profile (biggest win for "in Chennai" searches)
- Create a profile for Gari Tech. If there is no public office, choose "service area business" and hide the address. Set the service area to Chennai.
- Categories: Marketing agency, Internet marketing service, Social media agency, Website designer.
- Add website https://garitech.co.in, services, a short description, photos and the logo.
- Ask your six Google reviewers to also review the Business Profile. Reply to every review.
- Post an update every week or two (a new blog post, a new site you built).
- Use the same business name, phone and website everywhere.

## 2. Bing Places and Apple Business Connect
- Create the same profile on Bing Places (Bing feeds ChatGPT search and Copilot) and Apple Business Connect.

## 3. Profiles you own (all link to boobesh.com and garitech.co.in)
- LinkedIn personal profile: headline "Content Marketer in Chennai | Founder, Gari Tech". Put boobesh.com in Contact info and in Featured.
- LinkedIn company page for Gari Tech with the website and services.
- Instagram, X, YouTube bios: same one line description and a link.
- Substack and Beehiiv newsletters: bio links to boobesh.com.
- Make sure garitech.co.in links to boobesh.com, and boobesh.com links to garitech.co.in (already done on boobesh.com).

## 4. Directories and citations (real listings only)
- Clutch, GoodFirms, Sulekha, JustDial, IndiaMART (where relevant), Crunchbase.
- Use identical name, description, website and category on all of them.

## 5. Backlinks from places that already mention you
- Event and community pages where you spoke (Speak With Ikigai, CodeSapiens, D3 Community, Startup Atti, Think Digital, Startup Real OG Awards, E-Cell IIT Bombay): ask them to add your name with a link to boobesh.com.
- Clients you built websites for (Speak With Ikigai, Pranav Mahi, Essential Counselling Center, Gurusthetics, Instyle Uniform): ask for a small "website by Gari Tech" credit in the footer linking to garitech.co.in.
- College pages and student communities that featured you.
- Guest posts on student, startup and marketing blogs, with a bio link.

## 6. Content others will link to
- Publish original, specific posts (case studies, honest mistakes, checklists). Share each on LinkedIn the same day.
- Answer real questions on Quora and Reddit with useful answers (not links only), and mention your post only where it truly helps.

## 7. Search engines
- Google Search Console: submit https://boobesh.com/sitemap.xml, Request indexing for new pages.
- Bing Webmaster Tools: import from Search Console. Run `npm run indexnow` after deploys.
- LinkedIn Post Inspector (linkedin.com/post-inspector): re-scrape https://boobesh.com after changes.

## 8. Track it
- Once a month, note impressions, clicks and average position in Search Console for: boobesh, boobesh ag, gari tech, content marketer in chennai, marketer in chennai, content marketing agency in chennai.
