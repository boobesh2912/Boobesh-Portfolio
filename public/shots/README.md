Keep them under about 400kb. PNG for logos, JPG for photos.

Two things worth knowing. Renaming a file through the GitHub web UI has twice
now replaced the image with a two byte text file, so upload with the right
name instead of renaming afterwards. And event photos, blog thumbnails and
site screenshots do not belong here at all: add those at /admin and they
upload themselves into public/uploads.
